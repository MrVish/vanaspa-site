## Site structure

- `index.html` is the homepage, written by hand.
- The treatment, area, offers and journal pages (`/massage-kakkanad/`, `/deep-tissue-massage-kakkanad/`,
  `/couples-spa-kakkanad/`, `/offers/`, `/journal/…` and the rest) and `sitemap.xml` are generated by
  `_tools/build_pages.py`. They share `assets/css/pages.css`.

## Changing prices or page content

1. Edit `MENU` (prices) or the page text in `_tools/build_pages.py`.
2. Run `python3 _tools/build_pages.py` from the repo root. This rewrites the generated pages and `sitemap.xml`.
3. If a price changed, update it in `index.html` too: the menu section **and** the JSON-LD block near the top.
4. Commit everything and push.

Folders starting with `_` (`_tools/`, `_notes/`) are not published by GitHub Pages.
`_notes/local-seo-checklist.md` has the Google Business Profile and Search Console steps.
